# Layoffs Data Analysis Project

## Project Overview

This project explores worldwide layoff trends using SQL.

The analysis focuses on identifying patterns across companies, industries, countries, and years to uncover key business insights.

## Dataset

Layoffs dataset containing information about:
- Companies
- Industries
- Countries
- Funding stages
- Total employees laid off
- Layoff percentages
- Dates

## Tools Used

- MySQL
- SQL
- GitHub

## Project Workflow

### 1. Data Cleaning
- Removed duplicate records
- Standardized text values
- Handled missing values
- Corrected date formats

### 2. Exploratory Data Analysis
- Total layoffs by country
- Total layoffs by industry
- Layoffs by year
- Monthly layoff trends
- Top companies by layoffs
- Ranking companies using Window Functions

## Key Insights

- The United States experienced the highest number of layoffs.
- The Consumer industry was among the most affected sectors.
- Layoffs increased significantly during economic downturn periods.
- Several companies reported laying off their entire workforce.
